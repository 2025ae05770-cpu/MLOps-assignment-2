## 4. Metrics and Review

For Task 1 the notebook displays five v1 requests and mean, median, min, max, and
**sample** standard deviation of latency. The slowest request is identified with
its output tokens and status. Provider queuing, response length, and network
variability are possible explanations, not proven causal findings.

The required cost formula is:

```text
Input cost  = input_tokens  / 1,000,000 * input_price_per_million
Output cost = output_tokens / 1,000,000 * output_price_per_million
Total cost  = input_cost + output_cost
Monthly cost for 10,000 requests = average_request_cost * 10,000
```

`total_cost_usd` follows this standard-input assignment formula. A separate
`cache_adjusted_cost_usd` uses any provider-reported cached input tokens at their
published discount. Output usage includes billed reasoning tokens, if present.
Unknown usage/cost stays blank, never zero. Token and cost averages use responses
with known usage; latency uses all attempts. No incomplete version is promoted.
The monthly estimate excludes taxes, tools, hosting, unobserved retry costs,
and future workload changes. Reduce response length/redundant context, then
evaluate the optimized prompt as a new version before adopting it.

`valid_json` is strict JSON syntax validity divided by all five requests. Failed,
refused, truncated, empty, or missing-usage responses fail the evaluation. Code
fences, NaN/Infinity, and duplicate keys are rejected, with no output repair.
`schema_valid_rate` separately checks the exact three keys, string answer,
confidence enum, and array of strings. No API JSON mode is used for any version.

Review **all 15 responses** in `human_review.csv`. Do not edit measured responses,
IDs, references, or other evidence. Fill these review fields only:

| Field | Rubric |
| --- | --- |
| `accuracy_0_to_2` | 0: wrong; 1: partly correct/important omissions; 2: conceptually correct |
| `clarity_0_to_2` | 0: confusing; 1: understandable but verbose/awkward; 2: clear and concise |
| `relevance_0_to_2` | 0: off-topic; 1: partially addresses question; 2: directly answers it |
| `reviewer`, `notes` | Your name/initials and a concrete reason for the assessment |

Compare with the reference concepts rather than expecting identical wording.
A candidate must complete 5/5 requests, meet the exact schema 5/5, and obtain
accuracy=2, relevance=2, clarity>=1 on every answer. Among eligible versions,
choose the lowest mean cost, then lowest latency. Self-reported confidence is
not a correctness metric. No candidate passing means **do not promote**.
